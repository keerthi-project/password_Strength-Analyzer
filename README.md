# Password Strength Analyzer

## Project Description
Password Strength Analyzer is a Python-based
cybersecurity tool that evaluates password strength
and suggests improvements.

## Features
- Password length checking
- Uppercase and lowercase checking
- Number verification
- Special character verification
- Weak, Medium and Strong classification
- Strong password generation
- Common password detection

## Technologies Used
- Python 3
- Regular Expressions (re)
- Secrets Module
- String Module

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python "import re.py"

## Expected Outcome
The tool helps users understand password security
and create stronger passwords.
